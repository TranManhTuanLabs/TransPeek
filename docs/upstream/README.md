# Upstream docs (MoePeek)

These files come from the upstream project this repo was forked from,
[cosZone/MoePeek](https://github.com/cosZone/MoePeek). They are kept here
for reference only — do not update them to describe TransPeek.

- `RELEASING.md` — upstream release guide (Chinese).
- `releases/` — upstream release notes (MoePeek v0.19–v0.21). TransPeek
  never had these versions; its own releases start at v0.1.
- `plans/` — upstream release plan.

TransPeek's own docs live in `docs/` (e.g. `SPEC-v0.1.md`,
`M2-M3-TESTING.md`). When in doubt, the file in `docs/` is the one
that describes this repo.
